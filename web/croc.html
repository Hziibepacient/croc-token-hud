怎么读这个画面

奶瓶数量表示五小时剩余额度：每瓶约 20%，向上取整；额度未知或已过重置时间时不显示奶瓶。休息时奶瓶保留。

最近完成响应的平均输出速度分五档：不足 15、15–<30、30–<60、60–<100、≥100 tok/s，对应 1 / 1 / 2 / 2 / 3 行。速度越快，便便越密、向右移动越快。行数是档位，不代表输出总量。

规则与 Windows 桌面版共用同一份 Python 代码（croc_scene.py）。数据只来自本机 Codex 日志；未获得本轮速率时不移动，工具执行时暂停生成。
