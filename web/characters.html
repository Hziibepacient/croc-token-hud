第一次添加新形象？跟着这三步就好

在 Codex 里制作，回到这里预览和使用。已有角色包可以直接从第 3 步开始。

  1. 1

    准备喜欢的角色图片

    准备一张或多张清晰参考图，照片、插画都可以。多张图时，告诉 Codex 哪张是主参考、哪些只参考表情或动作。

    参考图发给 Codex，这里暂时不用上传。
  2. 2

    让 Codex 做好八个动作

    复制下方指令，在具备生图能力的 Codex 对话中粘贴，并一起附上参考图。让它完成八张动作图、检查位置，最后交付一个 ZIP。

    工具包也可以一起发给 Codex，里面有格式说明和检查工具，你不用自己写代码或安装 skill。

  3. 3

    拿到 ZIP，回来添加

    把 Codex 生成的角色包下载到电脑，再上传到这里，无需解压。填写你喜欢的名字，预览八个动作和工作喷射，满意后点“添加并使用”。

    以后右键桌面角色 → 更换形象，就能随时切换。
发给 Codex 时怎么说？生成后该检查什么？

粘贴完整指令、附上图片，再说：“请按指令完成八个动作并打包。第一张是主参考，其他图片只参考表情和动作。”只有一张图时，说明以这一张为准即可。

完成后应拿到一个包含八张透明 PNG 和角色配置的 ZIP，而不只是一张展示图。预览时看一下角色是否长相一致、切换时脚底是否稳定、便便是否从身体后面出现。若只得到图片或提示词，请让 Codex 继续完成打包。

如果生成中途停下，可以在原对话里说“继续完成剩余动作和角色包”。角色工作台负责检查、预览和导入；生成图片在 Codex 中完成。
